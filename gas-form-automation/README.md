# お問い合わせ管理の自動化（Googleフォーム × スプレッドシート × GAS）

Googleフォームに届いたお問い合わせを **管理シートに自動で登録し、担当者へメールで通知** する Google Apps Script です。
対応漏れを防ぐため、一定日数以上完了していないものを毎朝まとめて知らせます。

## できること

| 機能 | 内容 |
| --- | --- |
| 自動登録 | フォーム送信時に受付番号（例: `Q-20261007-003`）を振って管理シートに1行追加。同時送信でも番号が重ならないようロックで制御 |
| 振り分け | 種別（見積もり／不具合／その他）と本文の言葉（「至急」「動かない」など）から優先度を判定し、担当者を割り当て |
| 通知 | 新規受付をメールで通知（件名に受付番号と優先度） |
| 対応漏れ防止 | 毎朝9時、受付から N 日以上「完了」になっていないものを古い順に一覧にしてメール |
| 完了日 | ステータスを「完了」にすると完了日を自動入力、戻すと消去 |
| 設定 | 通知先・日数・種別ごとの担当者は「設定」シートで変更（コードの修正は不要） |

## ファイル

| ファイル | 内容 |
| --- | --- |
| `Code.gs` | シートの用意・トリガー登録（`setup`）、フォーム送信時の処理、毎朝の通知、完了日の自動入力 |
| `Logic.gs` | 優先度判定・受付番号・担当割り当て・未完了の抽出・通知文の作成（シートに触れない関数） |
| `appsscript.json` | タイムゾーンと権限（このスプレッドシートとメール送信のみに限定） |
| `test_logic.js` / `test_code.js` | Node.js でのテスト。`test_code.js` はスプレッドシートやメール送信を偽物に置き換えて全体の流れを確認 |

## 導入手順

1. Googleフォームを作り、質問を「お名前」「メールアドレス」「種別」「お問い合わせ内容」にする（種別は 見積もり／不具合／その他 の選択式）
2. フォームの「回答」→「スプレッドシートにリンク」で回答用のスプレッドシートを作る
3. スプレッドシートの「拡張機能」→「Apps Script」を開き、`Code.gs` と `Logic.gs` を貼り付ける
4. 関数 `setup` を選んで実行し、権限を許可する（「管理」「設定」シートとトリガーが作られます）
5. 「設定」シートで通知先メールと担当者を入力する

## テスト

```bash
node test_logic.js
node test_code.js
```

実際の Google 環境での動作は、テスト用のフォームとスプレッドシートで確認してから本番に設定してください。
質問名や列を変える場合は `Code.gs` の `HEADERS` と `handleFormSubmit` の項目名を合わせて変更します。
