# Portfolio

Web制作・業務効率化ツールの制作実績です。いずれも Claude Code を活用して開発しています。
掲載している店舗・企業・金額はすべて架空のものです。

| 作品 | 内容 | 技術 |
| --- | --- | --- |
| [lp-benriya](lp-benriya/) | 便利屋を想定した集客用ランディングページ | HTML / CSS / JavaScript |
| [list-extractor](list-extractor/) | 企業リストの抽出・重複削除・除外・Excel 出力ツール | Python / BeautifulSoup / openpyxl |
| [dashboard](dashboard/) | フリーランス向け案件・売上管理ダッシュボード | JavaScript（ライブラリなし） |

デモ: GitHub Pages で公開（`https://maromi0628.github.io/Portfolio/`）
