# Portfolio

Web制作・業務効率化ツールの制作実績です。いずれも Claude Code を活用して開発しています。
掲載している店舗・企業・金額はすべて架空のものです。

| 作品 | 内容 | 技術 |
| --- | --- | --- |
| [lp-benriya](lp-benriya/) | 便利屋を想定した集客用ランディングページ | HTML / CSS / JavaScript |
| [list-extractor](list-extractor/) | 企業リストの抽出・重複削除・除外・Excel 出力ツール | Python / BeautifulSoup / openpyxl |
| [csv-tool](csv-tool/) | ネットショップの注文CSVを取り込み形式に変換するツール（Shift_JIS 対応） | JavaScript / encoding-japanese |
| [dashboard](dashboard/) | フリーランス向け案件・売上管理ダッシュボード | JavaScript（ライブラリなし） |
| [invoice-maker](invoice-maker/) | 売上明細の Excel から取引先ごとの請求書を一括作成（軽減税率・インボイス対応） | Python / openpyxl |
| [gas-form-automation](gas-form-automation/) | Googleフォームのお問い合わせを管理シートに登録し、担当者へ自動通知 | Google Apps Script |
| [vba-order-sheet](vba-order-sheet/) | ネットショップの注文CSVを集計して注文書シートを作成する Excel マクロ | Excel VBA |

デモ: GitHub Pages で公開（`https://maromi0628.github.io/Portfolio/`）
