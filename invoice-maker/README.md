# 請求書一括作成ツール（Excel → Excel）

売上明細の Excel から、**取引先ごと・月ごとの請求書（Excel）** をまとめて作成するツールです。
毎月の請求書作成を、明細を貼り付けてコマンド1回で終わらせることを想定しています。

## できること

| 工程 | 内容 |
| --- | --- |
| 読み込み | 「日付・取引先・品目・数量・単価・税率」の列を名前で探す（列の順番は自由） |
| 入力チェック | 日付・数値・税率が読めない行や取引先が空の行は飛ばし、行番号つきで「読み込みエラー」シートに記録 |
| 集計 | 取引先×対象月ごとに明細をまとめる（`--month 2026-09` で1か月分だけも可） |
| 消費税 | 10%／8%（軽減税率）の混在に対応。インボイス制度に合わせて **税率ごとに1回だけ** 端数を切り捨て |
| 請求書 | 宛名・請求番号・発行日・登録番号・お支払期限（翌月末）・明細・税率別の小計と消費税・合計。A4 1枚に収まる印刷設定 |
| 一覧 | 作成した請求書の番号・金額・ファイル名を「請求一覧.xlsx」に出力 |

## 動作例（同梱の架空データ）

```
$ python make_sample.py
$ python make_invoices.py sample/売上明細.xlsx -o output
明細 9件 → 請求書 4件（合計 119,843円）
  読み込みエラー: 10行目: 数量が数値ではありません（'二本'）
出力先: output
```

`make_sample.py` が作る明細の取引先・金額はすべて **架空** です。エラー処理を確認できるよう、わざと1行だけ不正な値を入れています。

## 使い方

```bash
pip install -r requirements.txt
python make_sample.py                                   # 動作確認用の明細を作成
python make_invoices.py sample/売上明細.xlsx -o output \
  --issuer "請求元の名前" --registration T1234567890123 --address "住所"
python -m pytest                                        # テスト
```

レイアウト（列幅・見出し・支払期限など）は `write_invoice()` と `due_date()` で変更できます。
既存の請求書テンプレート（Excel）に差し込む形にも対応できます。
