# 注文CSVから注文書を作る Excel マクロ（VBA）

ネットショップ（楽天・Yahoo を想定）の注文CSVを複数まとめて読み込み、**商品コードごとの数量を集計した注文書シート** を作る Excel VBA マクロです。
毎日の「CSVをダウンロード → 手で集計 → 仕入れ先に発注」の手作業を、ボタン1つにすることを想定しています。

## できること

| 機能 | 内容 |
| --- | --- |
| 複数ファイル | CSV を複数選択して一度に集計（ショップが混在していてもよい） |
| 文字コード | Shift_JIS・UTF-8（BOM あり・なし）を「設定」シートの指定どおりに読み込み |
| 形式の自動判定 | 見出しの列名から、どのショップのCSVかを判定（列の順番が変わっても動く） |
| CSV の読み取り | ダブルクォートで囲まれた値の中のカンマ・改行・`""` に対応 |
| 集計 | 商品コードごとの合計数量・明細数・ショップ別の内訳。商品コード先頭の0は消さない |
| 二重計上の防止 | 期間が重なったCSVを両方選んでも、同じ注文・同じ商品は1回だけ数える |
| エラー一覧 | 数量が数値でない行・商品コードが空の行・重複は集計から外し、「エラー」シートにファイル名と行番号つきで記録 |
| 設定 | ショップの追加や列名の変更は「設定」シートで行う（コードの修正は不要） |

## サンプルデータでの結果

`sample/` の3ファイル（店名・注文番号・商品はすべて架空）をまとめて選ぶと、次の結果になる想定です。

| 商品コード | 商品名 | 合計数量 | 明細数 | ショップ別 |
| --- | --- | --- | --- | --- |
| 0050 | ギフト包装 | 2 | 2 | 楽天 1 / Yahoo 1 |
| A-001 | オリジナル マグカップ 白 | 4 | 3 | 楽天 3 / Yahoo 1 |
| B-010 | ドリップコーヒー 10袋, 中煎り | 6 | 3 | 楽天 4 / Yahoo 2 |
| C-200 | 木製コースター "ナチュラル" 4枚組 | 1 | 1 | 楽天 1 |

エラーシートには2件が記録されます。

- `楽天_1001.csv` の2行目：前日のファイルと同じ注文のため除外
- `yahoo_1001.csv` の5行目：数量が全角の「１」

重複の記録は、先に読み込まれたファイルが基準になります。

## 導入手順

1. Excel で新しいブックを開き、`Alt + F11` で VBA の画面を開く
2. 「ファイル」→「ファイルのインポート」で `OrderSheet.bas` を読み込む（日本語版 Excel 向けに Shift_JIS で保存しています）
3. ブックを「Excel マクロ有効ブック（.xlsm）」で保存する
4. マクロ `SetupSettings` を1回実行して「設定」シートを作る
5. マクロ `CreateOrderSheet` を実行し、CSV を選ぶ（Ctrl / Shift で複数選択）

実際のショップのCSVに使うときは、「設定」シートの列名をダウンロードしたCSVの見出しに合わせてください。
シートにボタンを置いて `CreateOrderSheet` を割り当てると、ボタン1つで実行できます。
