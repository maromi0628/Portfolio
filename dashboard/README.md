# 案件・売上ダッシュボード

フリーランス・副業の **候補案件 → 応募 → 作業 → 入金** を1画面で管理するダッシュボードです。
ビルド・サーバー・外部 API 不要で、`index.html` をブラウザで開くだけで動きます。

> 表示しているデータはすべて **デモ用の架空データ** です。

## 機能

- **概要**: 今月の手取り売上と目標達成率、入金待ち、進行中件数、作業時間、実績時給、月別グラフ、納期アラート
- **パイプライン**: ステータス別のカンバン。検収完了にすると入金予定を自動登録
- **候補案件**: 予算・想定時給・実現度でソート／絞り込み
- **作業ログ**: 案件ごとの作業時間と時給換算
- **売上**: 段階制の手数料を自動計算し、手取りと月別集計を表示
- 編集内容はブラウザ（localStorage）に保存、JS ファイルとして書き出し可能
- レスポンシブ・ダークモード対応、グラフは外部ライブラリなしの SVG

## 技術

HTML / CSS / JavaScript（フレームワーク・ライブラリなし）— Claude Code を活用して開発
